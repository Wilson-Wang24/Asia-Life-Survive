# Asia-Life-Survive

東亞各國生活困難指數：以台北＝100，比較亞洲 11 個城市與舊金山、雪梨的生活困難程度，並以台灣為基準，比較八國的所得、薪資、工時與物價。

**網站：** https://wilson-wang24.github.io/Asia-Life-Survive/

## 內容

- **生活困難指數**：把低薪、高房價、高物價、高工時合成一個分數，可切換城市／國家、房價算法與權重。
- **比較圖表**：人均 GDP、人均所得、平均年薪、年薪中位數、工時、時薪、房價所得比、物價與購買力，每張圖只比一件事。
- **民生日常消費**：固定用量的月消費籃，比較各城支出與占薪資的比例。
- **基礎統計與統計口徑**：所有原始數值、年份、口徑與來源連結，比較圖表可下載 CSV。

## 涵蓋範圍

- 國家：台灣、南韓、中國、新加坡、日本、泰國、美國、澳洲
- 城市：台北、台中、高雄、首爾、上海、北京、成都、青島、新加坡、東京、曼谷、舊金山、雪梨

## 資料來源

- 國家統計：IMF、世界銀行、各國統計機關與勞動部門（台灣主計總處、南韓國家資料處與雇用勞動部、中國國家統計局、新加坡人力部、日本國稅廳與厚生勞動省、泰國國家統計局、美國社會安全局與勞工統計局、澳洲統計局）、OECD
- 城市薪資：各地官方平均月薪，依當地稅制估算稅後
- 城市物價、房租、房價：Numbeo 2026 年中資料
- 匯率：美國聯準會 2025 年平均匯率

完整來源與口徑說明見網頁最下方「統計口徑與來源」。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網站，單一檔案，不需建置 |
| `scripts/net_pay.py` | 由官方平均月薪估算各城市稅後月薪 |
| `scripts/parse_numbeo.py` | 解析 Numbeo 城市頁，取出消費籃單價、房租與房價 |
| `CLAUDE.md` | 給 Claude 的專案說明：資料決策與待辦事項 |

## 注意

數字適合看大致排序與壓力來源，不宜解讀到個位數。城市房價與物價為群眾回報樣本，稅後薪資為估算值。
